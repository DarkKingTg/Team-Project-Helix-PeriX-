### Slide 2: The Problem – The ₹1.5 Lakh Crore Perishable Crisis
* **Headline:** Why Perishable Supply Chains Collapse
* **Visual:** 3 Problem Cards with warning badges:
  1. **Information Blackout at Farm Gate**: Farmers harvest blindly without predictive regional demand or modal price intelligence.
  2. **Static Pricing & Shelf-Life Decay**: Retailers hold fixed prices until produce softens, resulting in 100% total financial write-offs.
  3. **Fragmented Surplus & Competitor Friction**: Supermarkets and depots with excess inventory cannot sell to nearby commercial buyers without leaking their trade identity.
* **Speaker Script (30 sec):**  
  *"The perishable crisis happens because supply chain tiers operate in isolation. When farmers overproduce tomatoes, mandis get overwhelmed. Meanwhile, retailers 50km away face stockouts or let unsold inventory expire on store shelves. Traditional logistics lack real-time predictive elasticity and privacy-preserving surplus trade."*

### 🔵 Slide 5: The 10-Layer AI Supply Chain & Predictive Waste Pipeline
* **Headline:** Enterprise 10-Layer Autonomous Rebalancing Architecture
* **Visual:** The 10-Layer Pipeline Flowchart:

```
[Layer 1: Data Collection] ──> Farmer Logs + IoT Sensors (Temp/Humidity/Ethylene) + Weather + Agmarknet + Fleet GPS
             │
             ▼
[Layer 2: Data Ingestion]  ──> FastAPI + MQTT Telemetry + Async Message Streams
             │
             ▼
[Layer 3: Data Storage]    ──> PostgreSQL + PostGIS (Spatial) + Redis Cache + TimescaleDB Time-Series
             │
             ▼
[Layer 4: Data Processing] ──> Python + Pandas + NumPy Feature Engineering & Scalers
             │
             ▼
[Layer 5: Predictive AI]   ──> Agmarknet XGBoost (Price/Arrivals) + Prophet Time-Series Demand Forecaster
             │
             ▼
[Layer 6: Waste Risk Engine]─> Expected Waste (kg) + Waste % + Spoilage Probability + Remaining Shelf-Life (Hours)
             │
             ▼
[Layer 7: Optimization]    ──> Google OR-Tools Multi-Drop Routing + Cold Storage Allocation + Dynamic Markdown
             │
             ▼
[Layer 8: AI Agent Layer]  ──> LangGraph Reasoning + Multi-Step Tool Calling + Memory + Autonomous Planning
             │
             ▼
[Layer 9: Action & Response]─> POS Dynamic Markdown Sync + Logistics Route Push + Cold Chain Reservation + Alerts

             ▼

             │
```

  - **Preventive Optimization (Layer 7)**: Google OR-Tools multi-stop solver saving 18.2% transit distance.
  - **AI Agent (Layer 8)**: Autonomous LangGraph tool-calling coordinator executing decisions in &lt; 20ms.
  - **Feedback Loop (Layer 10)**: Real delivery outcome tracking triggering automated model retraining.
* **Speaker Script (40 sec):**  
  *"Our AI architecture operates across 10 specialized layers: from IoT sensor ingestion and Agmarknet predictive models to a perishability Waste Risk Engine, OR-Tools logistics optimization, and an autonomous AI Agent that dispatches automated actions—feeding real outcome logs back into continuous model retraining."*

###  Slide 6: Novelty – Anonymized B2B Surplus Marketplace
* **Headline:** Competitor-Safe Surplus Rebalancing with Escrow Clearing
* **Visual:** Mockup of anonymized listing card (`Protected Node #TN-CB-04`, `4.2 km away`, `45% OFF`, ` 36h left`)
* **How It Works:**
  1. A supermarket with 300kg excess ripe tomatoes lists them anonymously.
  2. Competing businesses cannot see the store's identity—only distance and grade.
  3. Nearby restaurants or sauce manufacturers claim the batch with **1-Click Smart Escrow**.
  4. Funds are locked, logistics are dispatched, and capital is recovered.
* **Speaker Script (30 sec):**  
  *"Our standout innovation is the Anonymized B2B Surplus Exchange. Normally, supermarkets won't discount inventory to competitors. In PeriX, store identities are completely masked. Nearby restaurants buy high-grade surplus at 40% off with automated escrow clearing—turning potential waste into immediate revenue."*
